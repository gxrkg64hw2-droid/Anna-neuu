# NOTICE — Private Academic Backup, Not a Distribution Channel

## Plain-English statement of intent

**This repository is set to PRIVATE on GitHub.** It is the personal cloud backup of one Bachelor student's in-progress thesis-tooling work. It is not, and was never, intended to function as a distribution platform for the literature PDFs it contains.

## To GitHub Trust & Safety / Moderation

If you are a GitHub Trust & Safety reviewer reading this, please consider the following before initiating a takedown:

1. **Privacy posture of the repository.** This repository has been private since creation (`gh repo create --private`). It has no public visibility, no published Pages site, no public Actions artifacts, no tagged releases that bundle the PDFs.

2. **Single-user access.** The only account with access to this repository is the owner (`nicremo`). No collaborators, no organization, no external access controls.

3. **Legal basis for the PDFs.** The PDFs under `thesen/*/pdfs/` and `_Luana/.../Literatur/` are research literature accessed by the repository owner and one fellow student under their respective university licenses (DHBW Mannheim institutional access). Inclusion in this private repository is for the purpose of building a per-student retrieval index for citation work. The PDFs are not redistributed, not embedded in any public artifact, and not accessible to anyone other than the owner.

4. **Personal-data context.** Identifying information (matriculation numbers, addresses, contact data of students and supervisors) appears in `PROJEKTUEBERSICHT.md` files and in source-document scans under `quelldokumente/`. This data is used solely as project metadata to drive the citation tooling. It is included with the consent of the persons concerned.

5. **Cooperation pledge.** If you have concerns about any specific file in this repository, please contact the owner via GitHub (@nicremo) or via the email shown in commit metadata before initiating a removal action. The owner can:
   - delete specific PDFs from the working tree and from git history within minutes,
   - or convert the repository to a PDF-free skeleton that retains only the open-source CLI tooling (which is licensed under MIT) and the personal academic notes,
   - or provide proof of institutional access for any specific paper.

## To anyone else who might somehow read this

This repository is private. If you are reading this NOTICE, you have legitimate access. Please do not share or copy any of the PDFs, transcripts, or personal data outside the scope of your access. The CLI code (everything under `rag/`, `tools/`, `tests/`, `templates/`, the spec/plan documents under `docs/superpowers/`) is MIT-licensed and you are free to fork and reuse it.
