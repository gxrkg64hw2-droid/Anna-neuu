# Profil: mixed-methods-mayring

Fuer qualitative und Mixed-Methods-Bachelorarbeiten mit Mayring qualitativer Inhaltsanalyse. Typisch fuer Konsumentenpsychologie, Sozialwissenschaften, qualitatives Marketing.

**Kapitelstruktur:** Einleitung -> Theorie -> Forschungsdesign -> Datenerhebung -> Kategoriensystem -> Auswertung -> Diskussion -> Fazit.

**Anhang:** Interviewtranskripte, Kodierleitfaden.

**Profil-spezifische Pakete:** `longtable`, `pdfpages`, `enumitem`.

**Profil-spezifische Templates:**
- `kategoriensystem.tex` - longtable-Vorlage fuer Mayring-Kategoriensystem
- `interview-anhang.tex` - PDF-Transkript-Includes
- `kodierleitfaden.tex` - Kodierleitfaden-Skelett

**Compile:** `cd thesen/<name>/tex && latexmk -lualatex main.tex`

**Empfohlene Skills:**
- `scientific-writing` fuer Einleitung, Theorie, Fazit
- `literature-review` fuer Stand der Forschung
- `statistical-analysis` mit `dach_reporting_standards.md` fuer Mayring-Reporting
- `scientific-critical-thinking` fuer Diskussion
